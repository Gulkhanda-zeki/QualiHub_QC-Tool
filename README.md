# Crextio Dashboard

A pixel-accurate recreation of the **Crextio** HR/employee SaaS dashboard — glassmorphism UI with warm cream-to-yellow gradient, progress metrics, work-time charts, calendar schedule, and onboarding tasks.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (typically `http://localhost:5173`).

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- Lucide React icons

## What's included

| Section | Components |
|---------|------------|
| **Navbar** | Crextio logo, 8 nav items, Settings, notifications, profile |
| **Header** | Welcome greeting, 4 metric progress bars, employee/hiring/project stats |
| **Left column** | Profile card (Lora Piterson), accordion sidebar with Devices |
| **Middle column** | Weekly work-time bar chart, circular time tracker, September calendar |
| **Right column** | Onboarding progress (18%), dark task list (2/8 complete) |
